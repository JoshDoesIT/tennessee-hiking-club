# Logo Usage Guidelines

## Primary logo

Use `high_res_master_2048.png` as the master raster source. Use the prepared smaller exports for websites and social platforms instead of repeatedly re-saving the master.

## Clear space

Keep at least 8% of the logo diameter as clear space on all sides when the badge sits inside a larger layout.

## Minimum size

- Full logo in normal web layouts: 160 px wide or larger is recommended.
- Small interface placements: use the prepared 64-128 px exports.
- Browser favicon: use the supplied favicon files. At very small sizes the badge remains recognizable, but the wording will not be readable.

## Do

- Keep the badge circular and proportional.
- Use the supplied full-color artwork without recoloring individual parts.
- Place it on simple, low-noise backgrounds.
- Keep adequate contrast and breathing room.

## Do not

- Stretch, skew, rotate, crop, or warp the logo.
- Change the internal color palette.
- Add drop shadows, glows, bevels, outlines, or filters to the badge.
- Re-type or replace the lettering inside the logo.
- Put the logo directly over visually busy photography without a clean backing area.

## Source note

The supplied brand artwork is raster PNG artwork. This kit does not label any file as a true vector master. If an SVG/EPS vector redraw is needed later, it should be rebuilt deliberately and proofed against the master artwork.
