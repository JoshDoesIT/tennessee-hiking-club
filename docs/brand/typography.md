# Digital Typography

The lettering inside the logo is part of the artwork and should not be recreated with a substitute font.

For website, email, and social graphics, use these companion fonts:

- Display / headings: **Oswald SemiBold**. Fallbacks: Impact, Arial Narrow, sans-serif.
- Body / UI: **Inter Regular / Medium / SemiBold**. Fallbacks: Arial, Helvetica, sans-serif.

Recommended hierarchy:

- H1: Oswald SemiBold, 48-64 px desktop / 36-44 px mobile
- H2: Oswald SemiBold, 32-40 px
- H3: Oswald Medium, 24-30 px
- Body: Inter Regular, 16-18 px, 1.5-1.7 line height
- Buttons/labels: Inter SemiBold, 14-16 px

Use all-caps sparingly outside the logo. The club name and short navigation labels can use all-caps; longer copy should use normal capitalization for readability.
